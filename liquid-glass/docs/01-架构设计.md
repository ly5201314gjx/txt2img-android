# 01 · 架构设计

## 1. 整体结构

```
┌─────────────────────────────────────────────┐
│ LiquidGlassHost（CompositionLocal 提供者）   │
│                                             │
│  ┌─ 背景层 Box ────────────────────────────┐ │
│  │  layerBackdrop(背景层)                  │ │  ← 渐变 / 壁纸
│  │  background { ... }                     │ │
│  └─────────────────────────────────────────┘ │
│  ┌─ 内容层 Box ────────────────────────────┐ │
│  │  layerBackdrop(内容层) + hazeSource     │ │  ← 页面内容（普通 UI）
│  │  content { ... }                        │ │
│  └─────────────────────────────────────────┘ │
│  ┌─ 顶栏（topBar）─────────────────────────┐ │
│  │  drawBackdrop（真玻璃）                 │ │  ← 玻璃顶栏
│  └─────────────────────────────────────────┘ │
│  ┌─ 浮层（overlay）────────────────────────┐ │
│  │  drawBackdrop（真玻璃）                 │ │  ← 玻璃底部导航等
│  └─────────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

## 2. 渲染原理

- **layerBackdrop**：把一个子树录制成独立的 `GraphicsLayer` 纹理（每帧更新）
- **rememberCombinedBackdrop(背景层, 内容层)**：把两张纹理合并为采样源
- **drawBackdrop**：玻璃组件绘制时，对采样源纹理施加效果：
  - `vibrancy()`：色彩活力增强（AGSL，API 33+）
  - `blur(12.dp)`：高斯模糊（RenderEffect，API 31+）
  - `lens(24.dp, 24.dp)`：镜头扭曲（AGSL，API 33+，**要求圆角形状**）
  - `Highlight.Default`：高光描边
  - `Shadow`：投影

## 3. ⚠️ 铁律：玻璃组件必须在内容层之外

**任何使用 `drawBackdrop` 的组件，绝不能放在 `content` 槽内。**

原因：内容层把整个子树录制成纹理；若玻璃组件在层内，它绘制时又去采样**自己所在的层**——
自采样 → 递归渲染 → 原生级崩溃（无 Java 异常可捕获，直接闪退）。

正确的放置：

| 槽位 | 位置 | 是否可放 drawBackdrop |
|---|---|---|
| `background` | 背景层内 | ❌（被采样，不应再采样） |
| `content` | 内容层内 | ❌（自采样崩溃） |
| `topBar` | 内容层之外 | ✅ |
| `overlay` | 内容层之外 | ✅ |

## 4. 层级内的视觉玻璃

内容层内的卡片/控件**不能**做 drawBackdrop，因此使用「视觉玻璃」：
半透明白容器 + 高光渐变描边，透过它能看到背景/内容，观感与真玻璃一致。

```
glassCard(shape)   大卡片：85% 白 + 渐变描边 + 弥散阴影
glassField(shape)  输入框/选择器底槽：28% 白 + 细高光边
glassChip(shape)   小胶囊/chip：55% 白 + 高光边
```

## 5. 主题与配色

玻璃表面颜色取自 `MaterialTheme.colorScheme.surface`（50% 透明度），
系统自动适配亮暗主题。
