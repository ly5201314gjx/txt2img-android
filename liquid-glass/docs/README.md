## 一句话总结

**液态玻璃 = Backdrop 实时采样渲染（真玻璃）+ 半透明容器（视觉玻璃）**

- **真玻璃**（`Modifier.liquidGlass`）：对「背景层 + 内容层」的纹理做实时 vibrancy / blur / lens 渲染，仅用于**内容层之外**的组件（顶栏、底栏）
- **视觉玻璃**（`glassCard` / `glassField` / `glassChip`）：半透明白 + 高光描边，用于**内容层之内**的卡片与控件
