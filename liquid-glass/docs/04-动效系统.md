# 04 · 动效系统

液态玻璃的"丝滑"来自三套动画的协同。

## 1. InteractiveHighlight —— 按压高光

文件：`ui/animation/InteractiveHighlight.kt`

```
按下 → 白色叠加层(0.06) + AGSL 径向高光(0.12，半径 1.2×minDimension)
       ↑ spring(0.5, 300) 动画
拖动 → 高光中心跟随手指
松手 → 弹簧回弹消退
```

- 高光位置可自定义：`InteractiveHighlight(scope) { size, offset -> ... }`
- AGSL 着色器（`layout(color) uniform`）部分 GPU 不支持时**自动降级**为纯叠加层，不崩溃

## 2. DampedDragAnimation —— 阻尼拖拽

文件：`ui/animation/DampedDragAnimation.kt`

底部导航指示器的核心：

```
按住   → pressProgress 0→1，scaleX/Y → pressedScale（弹簧）
拖动   → value 在 valueRange 内跟随手指，velocity 持续追踪
松手   → 等待 value 收敛到目标（快照流检测）→ 回弹到 initialScale
程序化 → animateToValue() 走 MutatorMutex，与手势互斥
```

velocity 驱动视觉效果（FloatingBottomBar 内）：

```
scaleX /= 1 - (velocity/10 * 0.75)   ← 快速滑动时横向拉伸
scaleY *= 1 - (velocity/10 * 0.25)   ← 纵向压缩
```

## 3. liquidGlass 修饰器的层变形

`Modifier.liquidGlass(shape)` 的 `layerBlock`：

```
progress = pressProgress
scale    = 1 + 4dp/height * progress        ← 按压放大
translation = maxOffset * tanh(0.05 * drag/maxOffset) * progress  ← 手指位移(阻尼)
scaleX/Y += 按拖动方向的非对称拉伸
```

## 4. FloatingBottomBar 的完整动效链

```
┌ 底座胶囊：vibrancy + blur(半径) + lens(半径)
│   └ 按压时：整体 scale 放大（lerp 1 → 1+16dp/width）
├ 指示器滑块：
│   ├ 位置 = dampedDragAnimation.value × 单 Tab 宽（可拖拽）
│   ├ 按压时：lens 增强 + Highlight 高亮 + Shadow/InnerShadow 渐显
│   ├ 拖动时：速度形变（见上）
│   └ 松手时：lens/高光/阴影随 pressProgress 消退
└ 图标：按住放大 1.2x（LocalFloatingBottomBarTabScale）
```

## 5. 手势监听 —— inspectDragGestures

`ui/animation/DragGestureInspector.kt`：在 **Initial 事件通道**先行监听、**不消费事件**，
所以玻璃组件能感知按压/拖拽，同时下层 LazyColumn 等滚动完全不受影响。
