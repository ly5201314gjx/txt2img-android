# 03 · 组件手册

## 宿主与修饰器

| API | 位置 | 说明 |
|---|---|---|
| `LiquidGlassHost(config, backgroundColor, background, topBar, content, overlay)` | `ui/LiquidGlassHost.kt` | 宿主：注册背景/内容层，提供 3 个 CompositionLocal |
| `Modifier.liquidGlass(shape)` | `ui/modifier/LiquidGlass.kt` | 真玻璃渲染（vibrancy+blur+lens+高光+按压动画），**仅限内容层外** |
| `isLiquidGlassEnabled()` | 同上 | 当前环境是否可渲染真玻璃（宿主内 + Android 13+） |
| `Modifier.glassCard(shape, alpha)` | `ui/card/GlassCard.kt` 等 | 视觉玻璃大卡片 |
| `Modifier.glassField(shape)` | 同包 | 视觉玻璃输入/底槽 |
| `Modifier.glassChip(shape)` | 同包 | 视觉玻璃小胶囊 |
| `glassHazeSource/glassHazeEffect(state)` | `ui/haze/GlassHaze.kt` | Haze 传统模糊兜底（Android 13 以下） |

## CompositionLocal

| Local | 类型 | 提供者 |
|---|---|---|
| `LocalGlassConfig` | `GlassConfig` | 宿主 |
| `LocalGlassBackdrop` | `Backdrop?` | 宿主（玻璃关闭时为 null） |
| `LocalGlassHazeState` | `HazeState?` | 宿主（enableBlur 关闭时为 null） |

## 顶栏

| API | 说明 |
|---|---|
| `GlassMediumFlexibleTopAppBar(title, subtitle, scrollBehavior, navigationIcon, actions, bottomContent)` | 玻璃顶栏；backdrop 可用时自动真玻璃，否则半透明+可选 Haze |
| `GlassTopAppBar(title, ...)` | 固定玻璃顶栏 |
| `GlassTopAppBarDefaults.containerColor()/scrolledContainerColor()/controlContainerColor()` | 玻璃配色 |
| `rememberGlassTopAppBarScrollBehavior()` | 自实现滚动折叠（不依赖 material3 实验 API），用法：`Modifier.nestedScroll(behavior.nestedScrollConnection)` |

## 按钮（顶栏用）

| API | 说明 |
|---|---|
| `GlassTopBarNavigationButton(onClick, ...)` | 返回按钮（液态玻璃样式） |
| `GlassTopBarActionButton(onClick, imageVector, ...)` | 动作按钮 |
| `GlassTopBarActionsRow { ... }` | 按钮行，可合并为单个玻璃胶囊 |

## 底部导航（原版全动效）

| API | 说明 |
|---|---|
| `FloatingBottomBar(selectedIndex, onSelected, tabsCount, isBlurEnabled, hasCustomIcons, modifier) { items }` | 真玻璃悬浮导航：可拖拽指示器、按压高光、速度形变 |
| `FloatingBottomBarItem(onClick) { icon + label }` | 单个 Tab 项 |

特性：
- 指示胶囊可**按住左右拖拽**切换 Tab（阻尼回弹）
- 按压时底座放大、图标放大 1.2x、lens/高光/内阴影随按压强度增强
- 快速拖动时胶囊速度形变
- 无玻璃环境自动降级为普通半透明胶囊

## 卡片

| API | 说明 |
|---|---|
| `GlassCard(...)` / `NormalCard(...)` | 玻璃卡片 / 普通卡片（透明容器色可配） |

## 动画基础设施（库内部，也可独立使用）

| API | 说明 |
|---|---|
| `InteractiveHighlight(scope, position)` | AGSL 径向高光跟随手指 + 弹簧动画（API 33+） |
| `DampedDragAnimation(scope, valueRange, ...)` | 阻尼拖拽：按压缩放、松手回弹、速度追踪 |
| `inspectDragGestures(...)` | 观察式拖拽手势（不消费事件，不干扰滚动） |
