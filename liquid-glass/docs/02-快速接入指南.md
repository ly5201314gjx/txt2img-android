# 02 · 快速接入指南

> 目标：把液态玻璃放进任意 Jetpack Compose 项目（3 步）

## 第 1 步：引入模块与依赖

```kotlin
// settings.gradle.kts
include(":liquid-glass")
```

```kotlin
// 项目根 build.gradle.kts（版本需与主项目一致）
plugins {
    id("com.android.library") version "9.2.1" apply false
    id("org.jetbrains.kotlin.plugin.compose") version "2.4.0" apply false
}
```

模块自身 `build.gradle.kts` 已声明以下依赖（如你的版本目录有冲突请对齐）：
`backdrop 2.0.0`、`haze 1.7.2 (+materials)`、`capsule 2.1.3`、Compose BOM 2026.06.01。

**最低要求**：compileSdk 37、Kotlin 2.3+（backdrop 2.0.0 的硬性要求）、Android 13+ 才有真玻璃渲染（低版本自动降级）。

## 第 2 步：套一层宿主

```kotlin
LiquidGlassHost(
    config = GlassConfig(          // 可选，不传用默认
        enableBlur = true,
        topBarButtonStyle = TopBarButtonStyle.LiquidGlass,
        useFlexibleTopAppBar = false,
        glassLevel = 2,            // 2 = 完整特效
    ),
    backgroundColor = MaterialTheme.colorScheme.surface,
    background = {
        // 背景层：渐变 / 壁纸 / 任何画面（玻璃的采样源之一）
        AsyncImage(model = wallpaper, contentDescription = null, modifier = Modifier.fillMaxSize())
    },
    topBar = {
        // 玻璃顶栏（内容层之外，可 drawBackdrop）
        GlassMediumFlexibleTopAppBar(title = "标题")
    },
    content = { _ ->
        // 页面内容（普通 UI，卡片用 glassCard / glassField / glassChip）
        Scaffold { padding -> ... }
    },
    overlay = {
        // 玻璃浮层（内容层之外）：底部导航等
        FloatingBottomBar(
            selectedIndex = { selectedTab },
            onSelected = { selectedTab = it },
            tabsCount = 3,
            hasCustomIcons = true,
            modifier = Modifier.fillMaxWidth(),
        ) {
            FloatingBottomBarItem(onClick = { selectedTab = 0 }) {
                Icon(Icons.Filled.Home, contentDescription = null)
                Text("首页", fontSize = 10.sp)
            }
            // ...
        }
    },
)
```

## 第 3 步：让内容层内的控件"玻璃化"

```kotlin
// 大卡片
Modifier.glassCard(RoundedCornerShape(12.dp))

// 输入框 / 选择器底槽
Modifier.glassField(RoundedCornerShape(8.dp))

// 小胶囊 / chips
Modifier.glassChip(RoundedCornerShape(10.dp))
```

## 版本兼容速查

| 组件位置 | 用什么 | 说明 |
|---|---|---|
| 背景层 | `layerBackdrop`（宿主自动） | 被采样 |
| 内容层 | `glassCard/Field/Chip` | 视觉玻璃 |
| 顶栏 | `GlassMediumFlexibleTopAppBar` | 自动检测 backdrop，可用则真玻璃 |
| 浮层底栏 | `FloatingBottomBar` | 真玻璃 + 全动效 |
| 任意组件 | `Modifier.liquidGlass(shape)` | 仅限内容层外使用 |

## 检查清单

- [ ] `LiquidGlassHost` 包裹根内容
- [ ] 玻璃组件（drawBackdrop）在 `topBar`/`overlay` 槽，不在 `content`
- [ ] `content` 内只用 `glassCard/Field/Chip`
- [ ] 顶栏用圆角形状（`RoundedCornerShape(0.dp)` 表示直角），**不要用 `RectangleShape`**（lens 特效不支持）
