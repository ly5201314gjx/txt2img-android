# 05 · 配置参数

## GlassConfig 全参数

```kotlin
GlassConfig(
    // ── 模糊 ──
    enableBlur: Boolean = true,          // Haze 传统模糊开关（Android 13 以下/无 backdrop 时兜底）
    enableProgressiveBlur: Boolean = false, // 渐进式模糊（顶栏 100% → 底部 0%）
    topBarBlurRadius: Int = 24,          // 顶栏 Haze 模糊半径
    topBarBlurAlpha: Int = 73,           // 顶栏 Haze 模糊透明度 (0-100)

    // ── 顶栏 ──
    topBarOpacity: Int = 100,            // 顶栏容器不透明度 (0-100)
    topBarButtonStyle: TopBarButtonStyle = LiquidGlass,
        // Plain / Tonal / Outlined / SemiTransparent / LiquidGlass
    mergeTopBarActions: Boolean = false, // 多个顶栏按钮合并为一个胶囊
    useFlexibleTopAppBar: Boolean = true,// 使用可折叠 MediumFlexible 顶栏

    // ── 底部栏 ──
    bottomBarBlurRadius: Float = 24f,    // 底部栏模糊半径
    bottomBarBlurAlpha: Int = 80,        // 底部栏不透明度 (0-100)
    bottomBarLensRadius: Dp = 24.dp,     // 底部栏镜头半径
    accentColor: Color = Color.Unspecified, // 底部栏图标强调色（Unspecified → primary）

    // ── 卡片 ──
    containerOpacity: Int = 100,         // GlassCard 容器不透明度 (0-100)

    // ── 玻璃渲染级别（自动分级测试）──
    glassLevel: Int = 2,
        // 0 = 不渲染玻璃（仅挂载层）
        // 1 = 基础模糊（RenderEffect，无 AGSL）
        // 2 = 完整特效（vibrancy + lens + 按压高光动画）
    glassConservative: Boolean = false,  // 保守模式：禁用 AGSL 着色器与按压高光
    glassSampleContent: Boolean = true,  // 内容层是否参与采样（false 时仅采样背景层）
)
```

## 与视觉效果的对应

| 想调什么 | 改哪里 |
|---|---|
| 玻璃更"厚"（更糊） | `liquidGlass` 的 `blur(12.dp)`、底部栏 `bottomBarBlurRadius` |
| 玻璃更透明/更实 | `liquidGlass` 的 `onDrawSurface` 表面 alpha、`bottomBarBlurAlpha`、`containerOpacity` |
| 高光更强 | `Highlight.Default`（可 copy 调整 alpha/宽度） |
| 顶栏随滚动变色 | `GlassTopAppBarDefaults.containerColor/scrolledContainerColor` |
| 顶栏按钮样式 | `topBarButtonStyle` |
| 禁用 AGSL（兼容性优先） | `glassLevel = 1` 或 `glassConservative = true` |

## TopBarButtonStyle

| 值 | 外观 |
|---|---|
| Plain | 裸图标，无容器 |
| Tonal | 淡色调容器 |
| Outlined | 描边容器 |
| SemiTransparent | 半透明容器（Haze 模糊） |
| **LiquidGlass** | **液态玻璃容器（Backdrop 实时渲染 + 按压动画）** |
